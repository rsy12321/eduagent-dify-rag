2. 审题 Agent 的清单第 3 条中举例（平均密度、浸没）来自前几轮暴露的问题，存在针对本评测集过拟合的风险。
3. 拒答准确率为关键词匹配，非语义判定；拒答时 Dify 仍返回无关引用（待处理）。
4. Q04/Q05/Q06（Run 2）出现 33–44s 离群延迟，原因未核实（疑似供应商排队）。

## 结论

- 路由与拒答：4 轮稳定 20/20、4/4。
- 答疑：更换 30B 级模型 + “多情况逐一结论”规则后，从 9/12 提升到 11–12/12。
- 出题：最难的环节。提示词自查规则效果有限；加入审题 Agent 后达到 4 轮最好（2/1/1），代价是出题延迟约 +9s。题目选项歧义、偏离指定主题仍是已知局限。
