# 初中物理·力学知识库讲义

## 范围与使用方式

面向八年级水平，覆盖机械运动、力、运动和力、固体压强、液体与大气压强、浮力、功和机械能、简单机械。用于教育助教的知识库检索、答疑及出题；由用户后续手动上传至 Dify。本次仅生成本地文档，不涉及模型配置或外部服务。

**内容为原创教学讲义，不含电学/光学/热学。** 所有段落和例题均为本任务原创编写，没有复制教材或网页原文。涉及机械能减少时只描述机械能的变化，不展开热学内容。

每篇使用相同的五个二级标题：`## 1 核心概念`、`## 2 公式与单位`、`## 3 常见误区`、`## 4 生活中的例子`、`## 5 小结`。需要使用重力系数时，均在该篇首次出现时说明取值为 10 N/kg。计算例题的已知量和结果均采用整数，采用单个公式直接代入的一步计算。

## 评测引用与字数口径

评测集位于工作空间的 `eval/questions.json`，人工阅读版为 `eval/questions.md`。题目中的出处采用“文件名#小节编号 小节名称”，例如 `02-force.md#3 常见误区` 对应文件中的完整标题 `## 3 常见误区`。这是逻辑出处标识，不依赖 Markdown 阅读器自动生成的网页锚点。
